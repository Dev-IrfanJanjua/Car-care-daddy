# Site media

Drop files here and tell Claude the filename + where it goes.
Anything in `public/` is served from the site root: `public/images/hero.jpg` -> `/images/hero.jpg`

## What the site needs (all currently placeholders)

| Slot | Suggested filename | Size | Notes |
|---|---|---|---|
| Logo (header) | `logo.svg` | any | SVG best; PNG with transparency also fine |
| Hero background | `hero.jpg` | ~1600x1600 | A car with visibly clear glass |
| Service card x4 | `service-windshield.jpg`, `service-glass-polish.jpg`, `service-headlight.jpg`, `service-detailing.jpg` | 600x400 | One per service |
| Before / after | `before.jpg` + `after.jpg` | 1200x750 | MUST be the same car, same angle, same lighting |
| Testimonial avatars | `review-1.jpg` ... | 128x128 | Optional; only with the customer's permission |

## Formats
- Photos: JPG or WebP. Keep each under ~300 KB.
- Video (optional hero background): MP4 / H.264, muted, 10-15s loop, under ~5 MB.
- Don't upload HEIC straight off an iPhone -- convert to JPG first.
